# Docs first

- Before you write or plan code that uses Laravel, Livewire or Flux, call SearchDocs with a few words about it (e.g. "single file component"), then ReadDoc the best match.
- Follow what the docs page or stub says, not what you remember: these are the versions this project uses, and your memory may be of an older one.
- To start a new file, look for a stub with SearchDocs and copy it, changing only names and content.
- Cite every docs page or stub you relied on, as `Source: <url>` under the code or step it supports.
- If the docs do not cover it, say so plainly. Never invent an API, option or file path.
