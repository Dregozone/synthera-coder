# Project conventions

- Keep changes minimal and focused on what was asked. Do not refactor, rename or reformat code you were not asked to touch.
- Follow the conventions already in the project (naming, folder structure, comment style) over your own preferences.
- Do not add or change dependencies (composer or npm packages) unless the user asks.
- After changing PHP files, propose running `vendor/bin/pint --dirty` and the relevant tests.
